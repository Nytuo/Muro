# Third-Party Notices

## Wallpaper Engine scene engine (`SceneEngine/`)

**An independent third-party dependency, not Muro's own code.** It is
[wallpaper-engine-rosetta](https://github.com/Nytuo/wallpaper-engine-rosetta),
linked into this tree as a git submodule at
`Muro/SceneEngine` rather than a plain directory.

## DepotDownloader (not bundled)

Workshop downloads run DepotDownloader
(https://github.com/SteamRE/DepotDownloader, GPL-2.0) as a separate process.
It is not part of Muro's source or release: Muro downloads the official
release from GitHub into `~/Library/Application Support/Muro/Tools` only when
the user asks for Workshop downloads to be set up.

## Phosphene

Parts of Muro's macOS wallpaper extension are derived from Phosphene:
https://github.com/kageroumado/phosphene
